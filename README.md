## 🚀 Como Rodar o Projeto

Basta dar **duplo clique** no arquivo:
- **`start-dev.bat`** (na raiz do projeto)

Ele abrirá automaticamente duas janelas de terminal dedicadas:
1. **Back-end API (Fastify)** em `http://localhost:3333`
2. **App Mobile (Expo)** com o QR Code para você escanear com o celular no **Expo Go**.
